# Contributing

Thank you for your interest in contributing to this repository.

This project is a curated collection of Python scripts with varying levels of complexity. Contributions are welcome, provided they follow the guidelines below.

---

## General Guidelines

- Keep contributions focused and purposeful
- Follow clean, readable Python standards
- Do not introduce unnecessary dependencies
- Maintain compatibility with Python 3.10+
- Avoid breaking existing scripts or structure

---

## Repository Structure

Please place new scripts in the correct category:

- `scripts/simple/`  
  Plug-and-play utilities with minimal configuration

- `scripts/intermediate/`  
  Scripts that require configuration or basic technical understanding

- `scripts/advanced/`  
  Advanced systems that require deeper knowledge to configure or extend

Shared or reusable logic should go in:
- `shared/`

Do not modify imported repositories unless explicitly requested.

---

## Code Style

- Use clear function separation
- Prefer explicit logic over clever tricks
- Add comments only where clarity is genuinely needed
- Avoid over-engineering

---

## Commits

- Keep commits small and focused
- Use clear commit messages (imperative tense)
  - Example: `Add configurable task timer script`
- One logical change per commit

---

## Submitting Changes

1. Fork the repository
2. Create a new branch for your change
3. Make your changes following the guidelines above
4. Ensure scripts run without errors
5. Submit a pull request with a clear description of what was added or changed
