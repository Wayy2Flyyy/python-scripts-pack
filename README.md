## 📦 Included Scripts

### ➕ Python Calculator
Lightweight calculation script focused on fast, accurate computations. Clean logic, minimal overhead, and easy integration into other projects.

A simple, modern login and registration interface built in Python. Designed to be extendable into a full desktop or authentication system.

A lightweight image conversion tool supporting formats such as PNG and JPEG. Handles single-file and batch conversions with minimal setup.

### ⏱️ Python Stopwatch
A clean, distraction-free stopwatch for tracking gameplay sessions, tasks, or work time with precision and reliability.
